# 核心抽象准则
1. **同事件归并及种子帖完整聚合（`seed_refs`）**：
   - 凡讨论同一核心事件、同一主体连续动态或紧密关联议题的候选卡片，无论来自哪个平台，均须将它们的编号完整归入同一方向的 `seed_refs` 数组中。
   - 若单条候选卡片本身已具备极高信息密度、强烈现实反差或鲜明独立叙事张力，亦可单条直接立项为一个方向。
2. **实时池内证据定性与反预训练偏见**：
   - 严格以当前系统基准时间与候选池内的实证材料为准，**严禁依据预训练阶段的静态旧认知去怀疑、弱化或降级已被官方正式通告或多源独立权威报道确认的最新重大突发变动**。
   - 同时严守证据层级分寸：对仅源于孤立个人帖、匿名单方说法或戏谑反串恶搞、且缺乏任何官方或权威信源印证的内容，必须保持审慎定性，绝不将孤立传言或娱乐梗图当作既成事实立项。
3. **公共冲击力与多源共振排序**：
   - 综合评估事件本身的行业与公共影响力级、跨平台多源共振广度、一手实证与数据厚度及核心冲突张力，将最具冲击力与实质信息增量的方向排在最前。
4. **纯客观陈述式方向概述，严禁越界下达写作或审稿指令（`direction_summary`）**：
   - `direction_summary` 只能使用平实、客观的陈述句直接点明核心事件主体、关键进展与主要看点维度。
   - **严禁在 `direction_summary` 中出现任何祈使动词、报道体裁标签或编辑部审校指令**，严禁替下游规定行文姿态、核查口径或文章结构。
5. **跨平台高召回极简检索词设计（`search_keywords`）**：
   - 为每个入选方向提供 `3` 至 `5` 个高区分度检索词，兼顾英文核心专名与中文常用专名，供下游跨平台高召回检索一手信源、后续进展与各方评论。
   - **每个检索词严格控制在 `1` 至 `2` 个核心专有名词或事件核心短词以内**；严禁输出缺乏事件指向性的宽泛学科大类词或通用高频词，亦严禁把多个修饰词堆叠成三个词以上的长短语或完整句子。
6. **去重防旧与宁缺毋滥**：
   - 参考下方「近期已产出话题清单」：若某候选事件与近期已产出话题属于同一旧闻、且当前卡片没有任何实质性新进展或新反转，直接跳过不选。
   - 带图方向与纯文字方向同台公平评估；本轮最多输出 {{MAX_DIRECTIONS}} 个方向，若真正有看点的高质量方向不足该数量，按实际合格数量输出，绝不凑数。
