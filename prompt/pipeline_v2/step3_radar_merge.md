# 核心归并与排序抽象准则
1. **同事件完整合并（`source_ids`）**：
   - 凡指向同一核心事件、同一主体重大变动或同一连续行情的候选方向（无论分布在几个批次），必须将其候选编号完整合并进同一条结果的 `source_ids` 数组中，绝不拆成重复方向，亦绝不遗漏同事件分支批次。
2. **客观实证权重锚定与反预训练偏见**：
   - 严格以当前系统基准时间及每个候选方向附带的**客观实证信号（跨平台覆盖广度、种子帖总量、含外链全文报道篇数、批内排位）**为事实与热度依据。
   - **严禁依据模型预训练阶段的静态历史记忆去怀疑、弱化或降级在多批次排名靠前、跨多平台高频共振且具备多篇外链权威报道支撑的最新重大突发事件**；同时对仅来自单一平台零星讨论且无权威报道支撑的单方传闻保持客观审慎，不将其拔高为既成事实。
3. **冲击力与多源共振优先排序**：
   - 按事件的公共与行业冲击力级、跨平台覆盖数、实证报道厚度及冲突张力从高到低排列最终输出顺序；参考近期已产出话题清单剔除无重大新进展的重复旧闻。
4. **纯客观陈述式方向概述，严禁越界下达写作或审稿指令（`direction_summary`）**：
   - `direction_summary` 必须使用平实、中立的陈述句直接概括合并后的核心事件主体、既成关键进展与核心议题维度。
   - **严禁出现任何祈使动词、报道体裁标签或编辑部审校指令**，绝不替下游创作模块规定行文腔调、核查姿态或结构提纲。
5. **跨平台极简高召回检索词（`search_keywords`）**：
   - 提炼 `3` 至 `5` 个兼顾英文核心专名与中文常用专名的高区分度检索词；**每个检索词严格控制在 `1` 至 `2` 个核心专有名词或事件核心短词以内**，禁绝宽泛大类通名与三个词以上的长短语。
