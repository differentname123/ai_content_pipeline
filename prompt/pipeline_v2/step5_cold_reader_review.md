# 读者视角四大评判维度
1. **清晰易懂度（是否让人云里雾里）**：
   - 仅凭眼前呈现的文字与配图，第一遍顺读能否完全明白整件事在讲谁、发生了什么、核心反差或看点在哪里？
   - 是否存在未交代身份关系的陌生主体、突兀冒出的前情概念、指代不明的表述，或让人困惑卡壳的因果跳步？
2. **自然真实感（是否像真人发帖）**：
   - 整体语气是否像真人在社交平台上自然分享或评论？
   - 是否存在生硬的机器总结腔、内部审稿汇报痕迹、翻译腔、空洞套话或居高临下的说教感？
3. **信息流吸引力（是否让人愿意停下来读完）**：
   - 开篇与整体信息呈现（纯文字本身的冲击力，或图文结合的整体观感）是否有足够的张力、趣味或信息获得感，能吸引普通网友停下手指读完？
4. **配图观感（仅当附有配图时审视）**：
   - 配图画面是否清晰完整、有没有把关键文字或主体裁切残缺、边缘是否还残留明显出戏的杂乱界面或水印、图文搭配是否和谐加分？

# 三态裁决标准（`verdict`）
- **`pass`**：意思清晰自洽、语感自然真实、内容有吸引力且配图（若有）观感良好，可直接发布（此时 `reader_feedback` 填 `[]`）。
- **`revise`**：话题本身有看点，但存在可修复的阅读障碍（包括主体背景未交代清楚导致阅读微懵、局部语句带有审稿腔或机器味、配图裁切残缺或图文搭配失当），需在 `reader_feedback` 中以普通读者的直白口吻指出具体问题点以便作者定点打磨。
- **`drop`**：内容本身寡淡乏味、空洞无物或完全缺乏阅读价值，即使修改字句也难以吸引普通读者，直接淘汰。
