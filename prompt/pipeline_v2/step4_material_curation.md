# 核心精选与防幻觉准则
1. **严格同向相关性核验（宁缺毋滥，绝不硬凑）**：
   - 关键词搜索可能带回仅包含相同专名或缩写、实则讨论完全无关事件的碰撞帖。凡偏离目标方向核心事件或议题的候选卡片，以及毫无事实增量的纯恶搞戏谑梗图、单行重复口号水帖，一律剔除。
2. **实时基准锚定与多源互补全量保留**：
   - 严格以当前系统基准时间与候选卡片实证为准，严禁因事件突破预训练静态记忆而误删真实的一手官方通告或权威媒体报道。
   - 凡真正围绕该目标事件、能够提供官方声明、外链深度报道细节、数据图表、后续勘误反转、当事方回应或不同社区犀利观点的候选卡片，全部纳入 `curated_items`，不人为限制保留上限。
3. **单条理由锚定核对（严防看串行与编号幻觉）**：
   - 每保留一个候选编号，必须在紧随其后的 `"reason"` 中用一句话（≤35字）写出**该编号卡片本身**提供的具体事实或视角锚点；若核对时发现该编号卡片内容与目标方向不符，严禁将其放入 `curated_items`。
4. **方向可行性判定（`is_viable`）**：
   - 若剔除跑题噪音后，剩余合格素材足以支撑产出一篇事实清晰、有实质看点的原创内容，`is_viable` 填 `true`；
   - 若所有候选帖均与目标方向无关或全部缺乏实质内容，`is_viable` 填 `false` 且 `curated_items` 必须输出空数组 `[]`。
