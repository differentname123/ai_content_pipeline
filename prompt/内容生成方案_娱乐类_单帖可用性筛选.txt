# 任务与目标
对 `<data>` 中批量输入的社交媒体原始帖子（每条含 `"post_id"`、配图张数 `"image_count"` 与纯文本 `"text"`，当前阶段不传真实图片）做低成本初筛，挑出最有可能在社区引发高停留、高讨论与强共鸣的活人感候选帖进入下一阶段看图精裁，并为保留帖提取标准化事件简签（`event_key`）。

# 正向放行标准（高召回优先）
1. **个体冲突与反差**：准确放行包含个体真实极端盈亏、荒诞翻车反转、绝境求生、奇葩实盘困境或扎心自嘲的活人故事。
2. **剥壳取瓜与宏观/资金冲突**：当原帖表层带有吐槽、新闻或数据表述，但核心事实指向公众人物反差事件、宏观或金融基础设施突发冲击、巨鲸或机构大额多空对冲与资金分歧、行业奇葩乱象或集体争议时，准确识别传播内核并放行。
3. **图文悬念留存**：当 `"image_count" >= 1`（尤其 `>= 2`），且配文为具备戏剧张力的悬念提问、装傻求鉴定、破防短句或反讽吐槽（核心包袱与对比位于配图中）时，完整放行交由下一阶段看图验真。
4. **实体简签提取（`event_key`）**：`keep: true` 且正文已点明具体主体与事件时，提炼 4~10 字的客观事件简签用于下游同源去重；若正文为纯悬念短句看不出具体主体，或 `keep: false` 时，必须填空字符串 `""`（严禁根据配图个数猜测事件或填抽象情绪词）。

# 冲突优先级与豁免机制
- **判定优先级**：高危合规红线一票否决 > 实盘与带图冲突豁免 > 常规淘汰边界。
- **实盘与带图豁免**：在未触犯下方第 6 条高危合规红线的前提下，凡 `"image_count" >= 1` 且核心叙事属于真实个体极端盈亏、濒临强平危机、巨鲸或机构大额持仓异动、突发事件冲击或行业知名人物反转冲突（即使文本顺带提及价格数值、仓位历程、杠杆收益率或普通风险提示），**均不得套用纯行情分析或常规资讯条款一刀切拒稿**，应优先放行交给下一阶段看图核实真伪。

# 淘汰边界（满足任一即判 `keep: false`）
1. **纯行情教学与常规数据流水账**：以单纯技术指标教学、周期点位指导或缺乏个体命运反差与突发冲突的常规财经数据榜单、资金流水账及固定资讯模板为主目的的帖子；
2. **商业引流与硬广**：软硬广推销、返佣链接、邀请码或冷门代币合约地址推广；
3. **带单营业与粉丝家书**：向固定粉丝汇报近期带单胜率、直播时间预告、停更休假计划或普通素人日常颜值自拍打卡；
4. **死板通稿与无图残缺水帖**：口吻死板的常规机构公关声明；以及 `"image_count" == 0` 且单凭文字完全无法获知前因后果的残缺感慨；
5. **脱离投资与资本生态的纯日常及平淡科普**：与广义金融投资、资产交易博弈（涵盖加密资产与跨市场衍生品实盘）及重磅财经争议无关的私人生活或纯日常消遣，以及平铺直叙毫无公众吃瓜争议的常规科普；
6. **高危合规红线（一票否决，严审内容实质，严禁按形式大范围误杀）**：仅当文本内容**实质**触犯以下情形之一时判定淘汰（`keep: false`）：纯粹运营带单晒群员报喜或以免费/付费策略名义招揽用户加入外部聊天室与社群（凡核心意图为带单引流或拉群的，严禁指望后续删链洗白）；宣扬网贷、消费贷或抵押资产搏命赌博；涉未成年人内容（含玩梗）；直接恶意抨击、造谣或嘲讽交易平台自身机制、故障或核心高管；以极小本金冲击天价暴富的极端挑战口号。**防误杀边界**：普通交易吐槽、正常行情争论、对行业人物抗压持仓的正面敬佩，以及客观引用群友或对话背景讨论均属正常表达，绝不得因为出现对话或群聊背景就一刀切淘汰。

# 输出格式
仅输出一个合法纯 JSON 数组（严禁代码块或解释说明），与 `<data>` 输入顺序一一对应（当 `keep` 为 `false` 时，`event_key` 必须为空串 `""`）：
[
  {
    "post_id": "string",
    "keep": true,
    "event_key": "string"
  }
]
