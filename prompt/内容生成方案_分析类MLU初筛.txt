# 任务
从下游「加密货币多模态论据提取」的数据网关视角，对 `<data>` 中批量输入的社交帖子做低成本纯文本前置初筛，只放行具备有效分析论据提取潜力的帖子。

# 合格论据的三要素闭环标准
单条有效论据必须闭环包含：**明确标的与方向立场 + 可核查的客观事实 + 因果推导机制**（条件式右侧计划须具备明确主方向倾向与触发结构）。
- **无配图帖（`images` 为空）**：必须仅靠正文文本独立凑齐上述三要素闭环，才判 `no_evidence: false`；严禁对无图帖脑补任何未写明的盘面形态或数据。
- **含配图帖（`images` 非空）**：仅当正文自身已明确给出标的、主方向倾向以及具体的图表结构或指标观测维度（如周期、关键价位结构、具体指标名称或链上/资金流/持仓维度），使缺失的微观读数合理预期可由配图补全时，方可放行（`no_evidence: false`）；**严禁仅因带图就对纯快讯、泛宏观转述或无立场数据罗列臆测“配图可补全”**。

# 淘汰与冲突裁决原则（命中任一即判 `no_evidence: true`）
1. **三要素残缺**：虽罗列了客观价格/涨幅/均线/持仓等数据快照或转述宏观新闻，但缺乏明确方向立场、缺乏价格传导因果推导，或仅为对立两方的对称双向模棱两可假设（缺乏主方向倾向）。
2. **交易点位优先级裁决**：交易策略/点位表若同时伴随具体盘面结构、指标依据或强图表观测维度，按分析依据放行；若仅有操作方向点位与空泛情绪口号而无具体周期、结构与因果支撑，按纯喊单淘汰。
3. **非分析水帖与噪音**：包括缺乏实质论据、仅有万金油套话或互动反问凑字数的拼装水文、单纯困惑提问或持仓求助、无数据支撑的主观臆断、晒单炫耀与引流营销、日常闲聊与情绪宣泄、缺乏价格传导逻辑的纯消息快讯，以及标题党/标签与核心标的主体错配的跨界乌龙（注意：仅当正文**在结尾之前**已完整闭环明确主方向立场、客观数据事实与因果推演链条时，才不得仅因文末附带一句修辞反问而误杀；凡通篇缺乏明确立场与因果却以反问收尾的，一律淘汰）。

# 输出格式
仅输出一个合法纯 JSON 对象，严禁任何代码块或解释说明。顶层 Key 与输入 `post_id` 100% 一一对应：
{
  "post_id": {
    "no_evidence": false,
    "reason": "不超过35字的简洁判定依据（点明三要素闭环或命中红线）"
  }
}
