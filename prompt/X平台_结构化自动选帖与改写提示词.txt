# 任务
面向 X (Twitter) 简中加密货币社区（Crypto Twitter）进行内容选品决策与发帖定稿改写。
你需要在 `<historical_x_posts>` 中提供的最新 50 条历史已发帖客观数据（含发帖账号、粉丝数、浏览量、点赞、评论、转发、收藏及文案）的对比下，对 `<candidate_posts>` 中的候选帖子进行严苛筛选，剔除平庸或撞题的内容，并将最具爆款潜力的帖子改写为可直接在 X 发布的最终定稿。

# 核心决策标准（对标历史爆款样本与漏斗选拔）

> **基准确认原则**：分析 `<historical_x_posts>` 时，应结合各账号的粉丝体量差异客观理解流量区间，切勿用高粉丝大号的极端峰值机械否决小体量账号的破圈潜质。决定内容能否突破初始冷启动池的核心在于**前 3 秒视觉/文案钩子张力、反差冲突、实锤配图与公域讨论/收藏欲**。

1. **S级（强烈必发 · 本批头部顶级爆款潜质）**：
   - 具备强冲突实盘反差、极端盈亏/风控博弈奇观、重大突发安全/异常事件实锤或知名生态角色戏剧性动态，配图具备直接视觉支撑与强围观讨论欲；
   - **审慎但不过度保守原则**：对于真实呈现视觉证据或链上/盘面异常的强冲突事件，只要改写文案如实采用客观审慎归因（如指明当事人陈述、链上显示或画面呈现，不把推测写成司法定论），**不得因“事件尚未官方终局定案”或“主体不够知名”而将本批最头部的爆款机械降级为 A 级**；
   - **优中选优标尺（严保质量、避免全盘降档）**：若整批候选均平庸或撞题，`selected_posts` 必须输出 `[]`，绝不为凑数放行低质内容；但当本批经严苛初筛后确实存在值得发布的高潜优质内容时，应在 `selected_posts` 中优中选优，将**最具爆发力与视觉实锤的榜首 1~2 条定为 `S` 级**，避免因过度保守全盘评 A。
2. **A级（推荐发布 · 稳健高潜）**：
   - 具备明确的戏剧冲突、反直觉账单或验证过的高流量题材特征，但整体爆发上限与稀缺度略次于本批榜首 S 级候选。
3. **淘汰（REJECT）**：
   - 撞题与炒冷饭：与历史近 50 条已发帖同题材、同事件、同人物同一波盈亏的，100% 淘汰；
   - 平庸低张力：散户日常小额常规挂单、无图纯文字吐槽、万年老梗、缺乏反差的中庸合格帖，100% 淘汰；
   - 非投资生态与缺证猜想：脱离金融交易、博弈生存与科技资本圈矛盾的生活杂谈，或核心爆点完全缺乏配图/客观记录支撑的臆测，100% 淘汰。

# X 平台专属文案改写规范与字数硬红线

1. **字数绝对硬红线（违反直接作废）**：
   - X 平台信息流滑动极快，正文必须短促利落、分段留白，拒绝任何说教长文。
   - **改写后正文（`final_x_text`）必须短促精悍，总长度控制在 80 ~ 125 个纯汉字以内（连同英文标的、标点与换行，总字符数严禁超过 138 字符且不超过 280 X 单位）**。
   - 正文第一行必须是直抛反差与冲突的“前 3 秒钩子”，核心账单/数据让读者看大图，正文绝不把图片当说明书逐字复述。
2. **彻底清除外站痕迹与去 AI 味**：
   - 彻底删除 `[允悲]`、`[doge]`、`[笑cry]` 等方括号表情；仅在情绪极点自然保留 1 个原生 Emoji（如 `😂`、`🚨`）；
   - 严禁出现“广场上”、“币友”等外站词汇；严禁出现带 `📊 •` 的战报排版或结尾鸡汤升华。
3. **精准挂载 Cashtag**：
   - 若涉及明确代币标的（如 BTC、ETH、SOL 等），在正文首次出现处规范书写半角 `$SYMBOL`（前后留空格，如 ` $SOL `），每篇最多挂 1~2 个核心代币，文末严禁堆砌无关标签。
4. **一楼破冰神评（`bait_comments`）**：
   - 给出 1~2 条适合小号在一楼抢评的短句（采用“灵魂追问”或“扎心补刀”），勾起陌生路人盖楼围观。

# 强制输出规范（必须且仅输出合法的 JSON 字典）

请仔细阅读上述候选帖与历史表现，**直接且仅输出一个合法的 JSON 对象**。必须以 `{` 开始，以 `}` 结束，严禁包含任何变量赋值前缀（如 `texts = `）、解释性文字或 Markdown 废话：

```json
{
  "selected_posts": [
    {
      "id": "<候选帖唯一ID，字符串格式>",
      "grade": "S",
      "decision_reason": "<1~2句话：对标历史爆款客观数据，说明为何判定为S级/A级>",
      "final_x_text": "<改写后可直接发推的最终正文，纯汉字严格在80~130字之间>",
      "selected_images": ["<保留的配图编号，如 [IMAGE_1]>"],
      "bait_comments": ["<一楼破冰神评1>", "<可选神评2>"]
    }
  ],
  "rejected_posts": [
    {
      "id": "<淘汰候选帖ID>",
      "reason": "<一句话淘汰原因，如：与历史第#XX条撞题/反差不足/非币圈垂直题材>"
    }
  ]
}
```

*注意：`selected_posts` 按推荐度从高到低排列。若本批候选无达到 S 级或 A 级潜质的内容，`selected_posts` 应输出为 `[]`。*
