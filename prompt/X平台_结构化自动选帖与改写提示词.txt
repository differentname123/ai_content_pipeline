# 任务
面向 X (Twitter) 简中加密社区选品与定稿。先对照 `<historical_x_posts>` 建立防重与写法标尺，再从候选池中严选最有可能冲出初始冷启动流量池的头部爆款（S 级每批 `0~2` 条，无真爆款宁缺毋滥），输出可直接发推的原生文案与抢评神评。

# 一、历史区间分工（严禁错把参考号当撞题禁用区）
`<historical_x_posts>` 内含两个物理隔离的区块：
1. **`<target_account_posted_history>`（唯一防重禁止区）**：仅代表当前待发账号自己近期已发过的推文。凡与之同事件、同钱包或同一人物同波操作的候选，**必须淘汰**。
2. **`<cross_account_viral_benchmarks>`（爆款风格标杆）**：来自对照账号的高浏览代表作，**仅用于校准题材烈度、钩子写法与篇幅标尺**。**绝对禁止**因为对照账号发过某个题材，就淘汰当前账号尚未发过的全新爆款！

---

# 二、选品与定级（宁缺毋滥，死守交易博弈垂直度）
- **一票否决**：
  1. 与 `<target_account_posted_history>` 同事件撞题；
  2. 脱离具体交易博弈的泛新闻、常规企业财报/IPO 播报、政策快讯或空泛鸡汤，以及纯情感、熟人借钱吵架等脱离交易盘面、连核心 `$SYMBOL` 都挂不上的泛生活八卦；
  3. 普通散户小额常规开单、无实锤截图的纯K线臆测、老梗旧闻或带引流二维码内容（例外：核心当事人/官方本尊下场打假辟谣并附对照实锤）。
- **`S` 级（每批 `0~2` 条）**：不与本号撞题 + 有硬实锤配图 + 3 秒看懂强反差，且命中高爆发基因之一：
  1. 极限生死盘面与强平对赌（贴近爆仓线死扛、天价剧烈反转、顶流交易员罕见掉头）；
  2. 极端资金/盈亏反差（微本滚出夸张倍率、天价踏空/卖飞、长周期盈利一夕回吐或归零）；
  3. 突发协议漏洞、消息前异常重仓或规则急刹；
  4. 极强喜剧反差或本尊下场打假名场面。
- **`A` 级**：真实有趣但罕见烈度次于 `S` 级的高潜候选；平庸水帖直接淘汰，不塞 `A` 级凑数。

# 三、X 原生爆款写法铁律
1. **临场人话优先，彻底消灭记者腔、段子手模板与说教**：
   - 写之前同时看 `original_text`（活人原话）与 `draft_text`。涉及个人极限盈亏、扛单、爆仓名场面时，优先保留或还原第一人称/现场直击口吻，保持情绪张力；
   - **严禁出现**“原帖称 / 原帖算账 / 当事人晒出 / 网传截图 / 一名买家称 / 链上追踪图显示 / 公告显示”等新闻记者转述腔；
   - **严禁使用**“本以为……结果……”、“这哪是……这是……”、“这已经不是……而是……”、“凭运气赚的……还给市场”等 AI 段子手套路与鸡汤金句，严禁末尾补写“只是估值没提现/真实性待验证”等自我拆台句、道德说教、同义总结废话或“看大图/点开图片”等导览词。
2. **弹性自然篇幅（服从故事密度，严守 `<= 130` 字安全红线，硬上限 `<= 140` 原字 / `<= 280` X 单位）**：
   - 前两行直抛最刺眼的数字反差或现场情绪立住钩子（不在开头堆砌长定语背景铺垫）。当 `original_text` 或 `draft_text` 用 `35~75` 字已经把笑点、槽点或反转打穿时，**直接干脆收手，严禁为了拉长字数硬扩成三段式小作文**；仅当事件确有多层具体数字与连续反转细节时，自然展开至 `80~115` 字并用短句换行，**严禁突破 `130` 字**，讲完最扎心那一刀立即戛然而止。
3. **精准挂载 `$SYMBOL`**：
   - 只要涉及明确可交易标的或关联度最高的头部币种，必须在正文自然位置挂载 `1~2` 个英文半角 `$SYMBOL`（前后各留一个空格），不堆砌无关标签。
   - 清除所有外站方括号表情、Markdown 星号及外站称呼，至多保留 1 个原生 Emoji。
4. **独立神评（`bait_comments`）**：围绕你的改写正文原创 2 条 `<= 22` 字的真实高频交易员一楼抢评（追问细节或扎心补刀），直接勾起路人盖楼。
