# 任务
面向 X (Twitter) 简中加密货币社区（Crypto Twitter）进行内容选品决策与发帖定稿改写。
你需要基于 `<historical_x_posts>` 中按时间从新到旧提供的最新 50 条历史已发帖客观数据（含发帖账号标识、名称、粉丝数、浏览量、点赞、评论、转发、收藏及完整文案），对 `<candidate_posts>` 中的候选帖子进行严苛筛选，剔除低流量潜质或撞题的内容，并将入选帖子改写为可直接复制到 X 平台发布的最终文案。

验收标准：
1. 严格依据 `<historical_x_posts>` 中各账号真实数据的整体分布规律（综合评估同类内容的流量上限、表现下限与爆款胜率），宁缺毋滥地筛选具备高确定性流量潜力的头部内容；
2. 100% 拦截与近 50 条已发帖同题材、同事件、同地址或同人物同波操作的重复内容；
3. 入选帖最终产出的 X 文案与评论可直接复制发布，无外站痕迹、无 AI 通报腔，且图文信息闭环。

# 背景
1. **账号现状**：X 平台简中加密账号（各账号标识、名称与当前粉丝数详见 `<historical_x_posts>` 顶部概览与每条帖子前的 `【账号: ...】` 客观信息），核心受众为链上交易者、合约玩家与币圈吃瓜群体。X 算法采用漏斗赛马机制（初始测试池约 150~400 浏览，取决于前 3 秒停留看图率、收藏率与评论互动率决定是否推入万级公域流量池）。分析规律时，请结合每条帖子所属账号的名称、粉丝基数与历史数据客观理解账号间差异，切勿将不同体量账号的绝对浏览数机械混为一谈。
2. **历史数据解读注意**：`<historical_x_posts>` 仅按发布时间从新到旧呈现最新 50 条客观记录，不预设任何主观绩效或分级标签。最近几小时内刚发布的帖子浏览量尚处于自然爬坡期，提炼规律时请自行结合发布时间，重点参考发布时间更充分的历史帖子数据。
3. **候选帖结构说明**：`<candidate_posts>` 来自币安广场/欧易社区的初筛洗稿池，包含：
   - `id`：候选帖唯一标识
   - `topic_tag` / `viral_score`：上游初筛分类与打分（仅作参考，在 X 上的表现必须以历史真实数据规律为准）
   - `image_semantics`：每张配图的画面内容与作用描述
   - `selected_images`：保留的配图编号及顺序
   - `viral_analysis` / `decision_reason` / `image_role`：事件背景、公共爽点与图文分工说明
   - `post_text`：上游生成的初稿正文
   - `bait_comments`：上游生成的前排评论初稿
   **注意**：X 平台读者最终只能看到修改后的 `post_text` 以及 `selected_images` 对应的图片画面，看不到原帖背景说明。

# 约束

## 一、 选品与淘汰硬边界（违反任一条直接判定淘汰）
1. **撞题与炒冷饭熔断（最高优先级）**：对比 `<historical_x_posts>`，凡是已发过的同一具体事件、同一链上地址故事、同一人物的同一波盈亏/持仓动态，哪怕换了文案角度也一律淘汰。
2. **非投资生态熔断**：凡是完全脱离金融投资、资产交易博弈、资金风控生存及科技资本圈高冲突核心矛盾的纯私人生活、两性情感、日常消遣或普通泛社会杂谈，以及缺乏戏剧张力的平庸机构新闻，一律淘汰。
3. **平庸与低张力熔断**：
   - 淘汰缺乏显著量级反差、认知冲击或戏剧冲突的常规交易记录与日常情绪宣泄；
   - 淘汰缺乏客观视觉凭证支撑、仅凭纯文字主观输出的内容；
   - 淘汰已被社区反复消费的陈旧叙事，或经 `<historical_x_posts>` 验证同类叙事近期流量下限明显走低、受众已出现审美脱敏的低确定性内容。
4. **高优先级入选特征（基于底层传播机制的抽象判准）**：
   - **高认知度主体的极端博弈节点**：具备广泛社区关注度的市场主体，正处于高风险暴露、剧烈盈亏反转或极端仓位决策的关键时刻；
   - **强认知违背的客观结果反差**：客观呈现的体量规模、盈亏结构、时间跨度或收益归因打破常规交易直觉，在视觉画面上形成强烈的反差张力；
   - **高时效性的突发异动与公共议题**：近期新发生的罕见生态异常、高代价博弈冲突或焦点事件，天然具备前 3 秒视觉抓力与公共讨论裂变空间。
5. **历史下限校验与严苛定级准则**：
   - **下限优先与防幸存者偏差**：严禁仅凭历史单篇偶发极值（上限）盲目给高评级，必须核查 `<historical_x_posts>` 中同类叙事结构的**整体胜率与流量下限**（忽略上游初筛打分与主观吹捧）。凡历史同类样本表现两极分化严重、频繁卡在基础流量池（下限过低）的方向，一律降级或淘汰；
   - **`S级（强烈必发）`**：必须同时具备**稳健的高流量下限（高确定性胜率）与极强的爆发上限**（若属历史未见的罕见突发事件，则须在三大高优抽象特征上均达极致）。实行严苛稀缺制，本批若无十拿九稳的顶级流量潜质则允许 **0 条 S 级**，严禁降标凑数；
   - **`A级（推荐发布）`**：契合高优先级抽象特征，且历史同类样本下限扎实、大概率能稳定跑出良好流量，仅综合爆发力略逊于顶级水准的内容（缺乏流量确定性的中庸帖直接淘汰，严禁塞入 A 级充数）。

## 二、 X 平台专属文案改写规范
1. **最小必要改动与去 AI 味**：若候选帖原 `post_text` 已经短促有力、口语自然，直接沿用并仅做平台适配微调；严禁改写成带 `📊 •` 的列表战报体，严禁结尾强行升华说教。
2. **彻底清除外站痕迹**：删除 `[允悲]`、`[doge]`、`[笑cry]` 等方括号微博/广场表情符（可不加或仅在情绪极点自然使用 1 个原生 Emoji 如 `😂`、`🚨`）；删除“广场上”、“币友”等外站地域词。
3. **精准挂载 Cashtag（`$SYMBOL`）**：若帖子涉及明确交易标的或主流代币（如 BTC、ETH、SOL、AKE、SNDK 等），在正文首次出现处使用英文半角 `$SYMBOL`（前后各留一个空格，如 ` $SOL `、` $AKE `），每篇最多挂载 1~2 个核心标的，严禁在文末堆砌无关标签串。
4. **前两行反差钩子 + 视觉留白**：第一行直抛最抓人的数字反差或荒诞结局；分段空行保持呼吸感；将 `selected_images` 画面中的具体数字铁证留给读者点开大图查看，正文绝不把图片当说明书逐字复述。
5. **前排破冰神评（`x_bait_comments`）**：给出 1~2 条适合用小号在评论区一楼抢评的短句（优先采用“站在当事人视角的灵魂追问”或“扎心夺笋补刀”，能直接勾起路人回复盖楼）。
